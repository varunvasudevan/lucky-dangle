# Changelog

All notable changes to Lucky Dangle are listed here.

## [1.0.0] - 2026-11-18

### Added
- First public release: one HTML file with no dependencies, MIT licensed.
- 12-point Verlet rope at 120 Hz, with gravity, damping and a light breeze.
- Stretchy pull with squash-and-stretch springs and a bouncy release.
- Six charms: Nazar, Hamsa, four-leaf clover, Daruma, Maneki-neko and a custom emoji.
- Rituals, hover jingle, twinkles and flick on tap.
- Re-hang anywhere along the beam; hide and show with a whip.
- Mouse and touch through Pointer Events; respects prefers-reduced-motion.
- Live demo on GitHub Pages.

### Changed
- Maneki-neko charm uses the 🐱 emoji instead of a bundled image.
